# 体育教案（@local/pe-lesson-plan）

在 Harness 侧边栏加一个「体育教案」入口：左边栏点图标打开填表式教案编辑器，内容默认取自老师的《教案_原稿备份.docx》，点「生成 Word 教案」直接在浏览器下载 A4 排版的 `.docx`。

## 生成的文档

- 标题 + 副标题（年级 · 课题 · 课型 · 时长）
- 基本信息表（学科/年级/课题/课时/课型/教材/授课教师/班级人数/教学风格）
- 教材分析、学情分析、教学风格
- 教学目标（运动能力 / 健康行为 / 体育品德 三条）
- 教学重难点（重点、难点、突破策略自动编号）
- 教学准备（器材、场地、安全）
- 教学过程表（环节 / 时间 / 教学内容与教师活动 / 学生活动 / 组织与要求），带表头重复、合计时长
- 设计意图、运动负荷、教学反思（填了才出现）
- 附件清单（勾选的 PPT 课件、随堂测试等，列在文档末尾；PPT 会附文件名链接）
- 随堂测试（勾选后随机生成 10 道体育选择题，附参考答案，可「换一套」）

空着的可选栏目不会在文档里留下空标题。

## 教学风格

面板第 2 步可选「活泼 / 严肃 / 愉悦」三种课堂气质；切换时下方的「风格说明」会自动换成该风格的预设写法（游戏竞赛贯穿、队列口令严格、鼓励合作体验），也可以按班级情况改写。选中的风格会写进教案的基本信息表和「教学风格」一节，随 Word 一起导出。

风格文案集中在 `src/plan.js` 的 `PE_STYLE_PRESETS`，要加第四种风格只需在数组里补一项。

## 附件与 PPT 课件

面板最后一步是「附件」：勾选需要随教案提交的 PPT 课件、随堂测试、学习任务单、评价量表，也可以在「其他附件」里每行补一项（如安全预案、场地布置图）。勾选结果会在 Word 末尾生成「附件」清单，按预设顺序编号，没勾就不出现。

勾选「PPT 课件」后：

- 生成 Word 时同步用当前教案内容生成一份 16:9 课件（封面、教材与学情、教学目标、重难点、教学准备、教学风格、每个教学环节一页、结束页），面板附件栏出现下载链接；
- 教案末尾的「附件」清单写成「1. PPT 课件：课件_年级_课题_日期.pptx」，文件名带超链接；
- 两个文件保存在同一文件夹时，点教案里的文件名即可打开课件（文件移动后链接失效，按文件名重新找即可）。

附件项集中在 `src/plan.js` 的 `PE_ATTACHMENT_PRESETS`，加新附件同样只需补一项；课件版式在 `src/pptx.js`。

勾选「随堂测试」后：

- 面板里会出现「随堂测试（10 题）」和「换一套」按钮，可展开查看题目与参考答案；
- 题目从体育题库中随机抽取，并结合本课课题、器材、热身与安全要求出题；选项顺序也随机；
- 教案末尾自动加一页「随堂测试」和「参考答案」，可直接打印给学生；
- 同一份教案的题目固定（按 `quizSeed` 生成），换一套或恢复原稿才会重新出题。

题库和出题逻辑在 `src/quiz.js`。

## 代码结构

```
src/plan.js    教案数据结构、默认内容（来自原稿）、归一化
src/quiz.js    随堂测试题库与随机组卷（seed 固定则题目固定）
src/docx.js    纯 JS 生成 DOCX：OOXML + STORE 方式 ZIP，无第三方依赖
src/pptx.js    纯 JS 生成 PPTX：按教案内容排版 16:9 课件，同样无依赖
src/panel.js   面板 UI（React，无 JSX）与样式（只用 --dsw-alias-* 主题 token）
src/main.js    注册侧边栏图标（sidebar.panellist）与主面板（main）
build.mjs      把 src/*.js 拼成 client.js，并做语法检查
```

## 改完代码后

```powershell
node build.mjs                                  # 重新生成 client.js
node tools/check-client.mjs                     # 渲染路径 + 生成按钮冒烟检查
node tools/build-sample.mjs default 教案.docx    # 用同一生成器产出样例 Word
node tools/build-ppt-sample.mjs full 课件.pptx   # 用同一生成器产出样例课件
```

`client.js` 改了之后，浏览器要刷新一次页面才会加载新模块。
